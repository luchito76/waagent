¿Dónde va el agente si no tienen web?
No importa. El agente vive en WhatsApp, no en una web. Eso es exactamente tu ventaja — no necesitan tener nada armado.
El flujo para el cliente es:
Tienen un número de WhatsApp que usan hoy para atender
           ↓
Lo convierten a WhatsApp Business (gratis, 5 minutos)
           ↓
Vos conectás ese número a Meta Cloud API
           ↓
El agente empieza a responder desde ese mismo número
Sus pacientes siguen escribiendo al mismo número de siempre. No cambia nada para ellos. Y para el dueño de la clínica tampoco necesita web, app, ni nada nuevo.
De hecho esto es un argumento de venta — cuando te digan "nosotros no tenemos nada de tecnología" la respuesta es: "Perfecto, no necesitan nada. Solo el WhatsApp que ya tienen."
